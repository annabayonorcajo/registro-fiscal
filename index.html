Integridad del Documento

Cada día registrado genera una firma digital criptográfica (Hash SHA-256). Este código vincula inmutablemente la fecha, su estado, las notas y las fotografías subidas. Cualquier modificación posterior de estos datos invalidará la firma, demostrando la integridad de su evidencia.

Criptografía y Validez

¿Cómo funciona el Hash SHA-256?

Un Hash es una "huella digital" única de sus datos. La aplicación coge la información que usted introduce y genera este código. Es imposible revertir el código para obtener los datos, pero es muy fácil verificarlo.

Los datos usados para firmar cada día son:

FECHA + ESTADO + PAÍS + NOTAS + [CÓDIGO_FOTOS] + NOMBRE_TITULAR

En el reporte PDF, cada día incluye su huella. Si Hacienda sospecha, puede regenerar el Hash con sus datos. Si coinciden, los datos no han sido modificados.
